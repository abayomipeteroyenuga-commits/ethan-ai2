# ETHAN AI Search Engine v5 Production Ready

A source-backed AI search experience built for Ethan Digital Academy.

## Included
- Search, AI Chat and Files modes
- All / Web / News / Images / Videos / Education / Discussions
- Nigeria, Africa and Global focus
- Recency filters
- Follow-up questions and source citations
- Voice input (browser support dependent)
- Search history and saved searches
- Safe Search protections
- Server-side OpenAI key handling
- API health check
- Rate limiting, request limits and hardened headers
- PWA files
- robots.txt + sitemap.xml
- Root `index.html` for direct local testing

See `DEPLOY.md` for production setup.
