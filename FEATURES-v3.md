# ETHAN AI Search v3

Inspired by current best practices in leading AI search products, while keeping an original ETHAN interface.

Implemented:
- AI overview with source links
- All / Web / News / Images / Videos / Education search modes
- Recency filters
- Follow-up questions with context
- Search suggestions
- Search history
- Saved searches
- Copy answer
- Source numbering and citation chips
- PWA support
- Dark mode
- Local index.html test mode
- Server-side API key protection
- Safety-focused system instructions

Deployment:
1. Push the extracted project to GitHub.
2. Deploy to Vercel.
3. Add OPENAI_API_KEY as a server environment variable.
4. Optionally set OPENAI_MODEL to a Responses API model with web search support.
5. Connect search.ethandigitalacademy.org.
